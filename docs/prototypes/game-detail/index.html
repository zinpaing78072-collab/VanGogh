Games · click-through study

One game,
four ways to press start.

Four directions for the page a Game card opens. Same starry shell as the app, same TheGamesDB record underneath — the difference is how the record is staged: a spotlight hero, a cinematic field report, a printed dossier, or a store-style poster-and-details page. Every value is real TheGamesDB data; screenshots and fanart come from the same API.

Static prototypes. No IPC, no backend, no navigation wiring. Fields map to the Game record (id, game_title, release_date, rating, genre, overview, posterUrl). Players, publisher and platform names are in the same source payload but the record does not carry them yet.
